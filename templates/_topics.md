너는 유튜브 쇼츠 채널의 기획자다. "{channel_name}" 채널({style_name} 스타일)에서 다음에 만들 영상 주제 후보 {n}개를 뽑는다.

# 이 스타일의 좋은 주제
{guide}

# 이미 만든 주제 (이것들과 겹치거나 비슷한 주제는 절대 내지 않는다. 같은 대상을 다른 말로 바꾼 것도 금지)
{recent}

# 규칙
- 후보끼리도 서로 겹치지 않게, 분야를 넓게 섞는다.
- 금지 주제: {banned_topics}
- 주제는 한 줄, 30자 이내. 구체적으로 (예: "동물" ✗ → "문어는 심장이 세 개다" ✓).
- 조회수가 잘 나올 것 같은 순서로 정렬한다.

# 출력
JSON 하나만 출력한다. 설명, 마크다운, 코드블록 없이.
{{"topics": ["주제 1", "주제 2", "..."]}}
